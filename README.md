# DUCES Website V6

This repository contains the DUCES Consultancy Services website.

## V6 review improvements
- Reinforced the Royal Blue brand identity using the approved palette: Royal Blue `#123B70`, Corporate Blue `#1976B9`, Emerald Green `#008F6B`, Champagne Gold `#D9AD55`, White and soft neutrals.
- Added distinct hero treatments by service page to avoid repeating the same hero photograph across the site.
- Kept the supplied DUCES logo, Free Zone marks and banking, accounting, tax and PRO images.
- Improved search metadata with canonical URLs, Open Graph metadata and Organization structured data.
- Added a privacy policy page and linked it from the site footer.
- Completed the sitemap and corrected robots.txt formatting.
- Added image lazy-loading for below-the-fold service imagery and visible keyboard focus styles.
- Strengthened the Royal Blue proof/trust band and confirmed desktop navigation visibility.

## Enquiry form
The current contact form prepares an email using the visitor's email application. It does not send data automatically from the website. A secure form endpoint would be required for server-side submissions.

## Publishing
The GitHub Pages workflow deploys from `main`. Changes on the review branch are not live until they are reviewed and merged into `main`.
